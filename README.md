# 🎯 Reaction Game in C++ with Arduino

Проєкт **«Reaction Game»** — це інтерактивна гра на швидкість реакції, побудована на світлодіодній RGB-матриці **NeoPixel (WS2812B) 8x8** та мікроконтролері **Arduino Mega 2560** (або Uno/Nano).

---

## 🎮 Як грати?

1. **Старт:** При включенні або рестарті матриця чекає на натискання кнопки.
2. **Процес:** Світлодіодна точка швидко бігає ліворуч-праворуч у центральному рядку.
3. **Ціль:** Натиснути кнопку в той момент, коли точка знаходиться **точно посередині** (стовпчики `3` або `4`).
4. **Результат:**
   * **Влучання (Hit):** Матриця блимає **зеленим**, гра переходить на наступний рівень, а швидкість руху точки зростає.
   * **Промах (Miss):** Матриця блимає **червоним**, гра показує кількість пройдених рівнів і скидається на 1-й рівень.

---

## ⚙️ Основні технічні особливості

* **Скінченний автомат (Finite State Machine):** Логіка розділена на чіткі стани (`WAIT_TO_START`, `PLAYING`, `SUCCESS`, `GAME_OVER`).
* **Апаратна кнопка:** Використання внутрішнього підтягуючого резистора (`INPUT_PULLUP`) та програмне усунення дребезгу контактів (Debounce).
* **Динамічна складність:** Швидкість оновлення кадрів зменшується після кожного успішного раунду.
* **Неблокуючі таймери:** Рух точки та обробка дій відбуваються через `millis()`.

## 🔌 Схема підключення (Pinout)

> **⚠️ Примітка:** Кнопка підключається між піном `2` та `GND`. Завдяки `INPUT_PULLUP` додаткові зовнішні резистори не потрібні!

| Компонент | Вивід | Пін Arduino Mega 2560 |
|---|---|---|
| **NeoPixel Matrix** | DIN (Data In) | **Digital Pin 6** |
| | 5V / VCC | **5V** |
| | GND | **GND** |
| **Push Button** | Пін 1 | **Digital Pin 2** |
| | Пін 2 | **GND** |
